# Form Data Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a central form-intake service at `forms.anthonyduke.com` that stores submissions from any of our sites in one database, notifies managers by email without including the data, and blocks spam with Turnstile plus a honeypot.

**Architecture:** Plain PHP 8 on shared cPanel hosting, no framework and no package manager, following the structure already proven in `~/code/kevin60`. A single public endpoint (`api/submit.php`) authenticates a per-form secret key, runs spam checks, stores an accept-anything JSON payload, and sends a data-free notification. A login-gated `admin/` reads that data with per-form scoping. One file (`client/formdata-client.php`) ships to consuming sites.

**Tech Stack:** PHP 8.x (service) / PHP 7.0+ (client), PDO, MySQL (prod) + SQLite (dev), Cloudflare Turnstile, zero-dependency test runner.

**Spec:** `docs/superpowers/specs/2026-09-23-formdata-design.md`

**Scope:** Spec phases 1–3 (the service), plus deployment, plus the single pilot form. Migrating the remaining seven forms is phase 4 and gets its own plan.

**Repo:** All tasks create `~/code/formdata` as a new git repo, *except* Task 14 which edits `~/code/beta`.

**Deliberately deferred from the spec:** §7's *optional* authenticated SMTP is not built here. Notifications send via `mail()` on the forms subdomain, which is the same choice already made for TBD_v5 (commit `1372c17`, "send via local mail() by default — no SMTP creds needed"). The mailer is an injected callable in every code path, so adding SMTP later is a single new function and no change to callers, and `notification_log` will tell us if `mail()` is actually failing before we spend effort on it. Building an unused SMTP path now would be speculative.

## Global Constraints

- Service targets **PHP 8.x**. `client/formdata-client.php` must run on **PHP 7.0+**: no arrow functions, no named arguments, no typed properties, no `??=`, no constructor promotion, no `match`, no union types.
- **All queries use PDO prepared statements.** No string interpolation into SQL, ever.
- **Escape attacker-controlled field names *and* values** wherever the admin renders a payload. A field named `<script>` must be as safe as one named `email`.
- `config.php` is **gitignored** in the service and in every consuming site. `config.sample.php` is the committed template. Secrets never enter git.
- **The API returns generic errors.** An authentication failure must not reveal whether a form slug or prefix exists.
- MySQL and SQLite schemas are kept **identical in shape**. `payload` is `TEXT` holding JSON, never a MySQL `JSON` column.
- **Keys are stored hashed**; the full key is displayed exactly once, at creation or regeneration.
- **No public signup page.** Accounts come from `tools/create-user.php` or the owner.
- **Notification email contains no submission data** — form name, timestamp, and a link only.
- **A notification failure never fails the submission.**
- Rate limit default: **10 per 10 minutes** per `form_id` + `ip`. Rate-limited attempts store no row.
- Spam is stored with `status='spam'` and purged after **30 days**.
- Timestamp is HMAC-signed and submitted as `_ts` + `_sig`.
- Every `src/*.php` file starts with the guard `if (!defined('FORMDATA')) { http_response_code(403); exit('Forbidden'); }`, mirroring kevin60.
- Payload caps: **100 fields max, 32KB per value, 64KB total JSON.**

## Review Focus

Five failure modes the spec implies but does not pin down. Each has a test assigned to the task that owns the code.

1. **Array/checkbox fields** (`name="interest[]"`) — TBD_v5's volunteer form already uses time-block checkbox groups, so `$_POST` will contain arrays on day one of the pilot. Payload must preserve them and CSV must flatten them readably. *(Tasks 4 and 12)*
2. **Browser autofill filling the honeypot** — password managers and autofill happily fill hidden fields with recognizable names, silently marking real people as spam. The honeypot needs a non-semantic name plus `autocomplete="off"` and `tabindex="-1"`. *(Tasks 9 and 5)*
3. **A legitimate submission faster than 3 seconds** — autofill or a two-field form can beat the timing check. A real person must never be silently discarded: the row is still stored (as spam, so it is recoverable in the admin) and the visitor is told it failed rather than shown a false success. *(Task 5)*
4. **Invalid UTF-8 in a field** — `json_encode()` returns `false` on malformed UTF-8 (a real risk from Word/Outlook copy-paste), which would store an empty payload while the API cheerfully returns `ok`. Must be sanitized before encoding. *(Task 4)*
5. **Turnstile verification timing out or failing to connect** — if that fails closed, one Cloudflare blip takes down every form on every site at once. Transport failure must **fail open** (honeypot and timing still ran); only an explicit negative verdict rejects. *(Task 5)*

Additionally, CSV values beginning `=`, `+`, `-`, or `@` are formula-injection vectors when the export is opened in Excel, and are neutralized in Task 12.

```php
<?php
if (!defined('FORMDATA')) { http_response_code(403); exit('Forbidden'); }
function formdata_pdo(array $config) {
    $db = $config['db'];
    if (($db['driver'] ?? 'mysql') === 'sqlite') {
        $path = $db['sqlite_path'];
        if ($path !== ':memory:' && !is_dir(dirname($path))) { @mkdir(dirname($path), 0775, true); }
        $pdo = new PDO('sqlite:' . $path);
    } else {
        $m = $db['mysql'];
        $dsn = "mysql:host={$m['host']};dbname={$m['name']};charset={$m['charset']}";
        $pdo = new PDO($dsn, $m['user'], $m['pass']);
    }
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    $pdo->setAttribute(PDO::ATTR_DEFAULT_FETCH_MODE, PDO::FETCH_ASSOC);
    $pdo->setAttribute(PDO::ATTR_EMULATE_PREPARES, false);
    return $pdo;
}
```

```php
<?php
define('FORMDATA', 1);
$GLOBALS['T_PASS'] = 0; $GLOBALS['T_FAIL'] = 0; $GLOBALS['T_FAILURES'] = array();

function t_ok($label, $cond) {
    if ($cond) { $GLOBALS['T_PASS']++; echo "  ok   $label\n"; }
    else { $GLOBALS['T_FAIL']++; $GLOBALS['T_FAILURES'][] = $label; echo "  FAIL $label\n"; }
}
function t_eq($label, $expected, $actual) {
    $ok = ($expected === $actual);
    if (!$ok) {
        $GLOBALS['T_FAIL']++; $GLOBALS['T_FAILURES'][] = $label;
        echo "  FAIL $label\n       expected: " . var_export($expected, true)
           . "\n       actual:   " . var_export($actual, true) . "\n";
    } else { $GLOBALS['T_PASS']++; echo "  ok   $label\n"; }
}
function t_throws($label, callable $fn) {
    try { $fn(); t_ok($label, false); } catch (Throwable $e) { t_ok($label, true); }
}
/** Fresh in-memory SQLite with the schema applied. */
function t_pdo() {
    $pdo = new PDO('sqlite::memory:');

    $pdo->exec(file_get_contents(__DIR__ . '/../sql/schema.sqlite.sql'));
    return $pdo;
}
function t_config($over = array()) {
    $cfg = require __DIR__ . '/../src/config.sample.php';
    return array_replace_recursive($cfg, $over);
}
```

### Task 2: Keys and HMAC timestamp signing

**Files:**
- Create: `~/code/formdata/src/keys.php`
- Test: `~/code/formdata/tests/test_keys.php`

**Interfaces:**
- Consumes: nothing from earlier tasks
- Produces:
  - `formdata_generate_key(): array` → `array('key' => string, 'prefix' => string, 'hash' => string)`
  - `formdata_key_parse(string $key): ?array` → `array('prefix' => string, 'secret' => string)` or `null`
  - `formdata_key_hash(string $secret): string`
  - `formdata_key_verify(string $secret, string $hash): bool`
  - `formdata_sign_ts(string $ts, string $keyHash): string`
  - `formdata_check_ts(string $ts, string $sig, string $keyHash, int $now, int $minAge, int $maxAge): ?string` → `null` when valid, else the reason `'timing'`

**Design note for the implementer:** the key is `fd_<prefix>_<secret>` where prefix is 8 hex chars and secret is 64 hex chars (256 bits). The API looks the form up by `key_prefix`, then verifies the secret against `key_hash`. Hashing is plain SHA-256 with `hash_equals`, **not** `password_hash`: the secret is high-entropy random rather than a human-chosen password, so bcrypt's brute-force resistance buys nothing while costing time on every submission. The timestamp HMAC uses the **key hash** as its HMAC key — the client derives it from the secret it holds, the API reads it from the database, so both sides agree without the API ever storing the secret.

- [ ] **Step 3: Write minimal implementation**

`src/keys.php`:

```php
<?php
if (!defined('FORMDATA')) { http_response_code(403); exit('Forbidden'); }

function formdata_generate_key() {
    $prefix = bin2hex(random_bytes(4));      // 8 hex chars
    $secret = bin2hex(random_bytes(32));     // 64 hex chars
    return array(
        'key'    => 'fd_' . $prefix . '_' . $secret,
        'prefix' => $prefix,
        'hash'   => formdata_key_hash($secret),
    );
}

function formdata_key_parse($key) {
    if (!is_string($key) || !preg_match('/^fd_([0-9a-f]{8})_([0-9a-f]{64})$/', $key, $m)) {
        return null;
    }
    return array('prefix' => $m[1], 'secret' => $m[2]);
}

function formdata_key_hash($secret) {
    return hash('sha256', $secret);
}

function formdata_key_verify($secret, $hash) {
    return hash_equals($hash, formdata_key_hash($secret));
}

function formdata_sign_ts($ts, $keyHash) {
    return hash_hmac('sha256', (string)$ts, $keyHash);
}

function formdata_check_ts($ts, $sig, $keyHash, $now, $minAge, $maxAge) {
    if (!is_string($sig) || $sig === '' || !ctype_digit((string)$ts)) { return 'timing'; }
    $expected = formdata_sign_ts($ts, $keyHash);
    if (!hash_equals($expected, $sig)) { return 'timing'; }
    $age = $now - (int)$ts;
    if ($age < $minAge || $age > $maxAge) { return 'timing'; }
    return null;
}
```

```php
<?php
if (!defined('FORMDATA')) { http_response_code(403); exit('Forbidden'); }

function formdata_control_fields() {
    return array('_ts', '_sig', 'fd_hp', 'cf-turnstile-response');
}

/** Force a string to valid UTF-8, assuming Windows-1252 for stray high bytes. */
function formdata_utf8($s) {
    if (mb_check_encoding($s, 'UTF-8')) { return $s; }
    $converted = @mb_convert_encoding($s, 'UTF-8', 'Windows-1252');
    if ($converted !== false && mb_check_encoding($converted, 'UTF-8')) { return $converted; }
    return mb_convert_encoding($s, 'UTF-8', 'UTF-8'); // last resort: drop bad bytes
}

function formdata_clean_fields(array $post, array $limits) {
    $skip   = formdata_control_fields();
    $fields = array();
    $total  = 0;

    foreach ($post as $name => $value) {
        if (in_array($name, $skip, true)) { continue; }

        if (is_array($value)) {
            $clean = array();
            foreach ($value as $item) {
                if (is_array($item) || is_object($item)) {
                    return array('fields' => array(), 'error' => 'unsupported_field');
                }
                $s = formdata_utf8((string)$item);
                if (strlen($s) > $limits['max_value_bytes']) {
                    return array('fields' => array(), 'error' => 'value_too_large');
                }
                $total += strlen($s);
                $clean[] = $s;
            }
            $fields[formdata_utf8((string)$name)] = $clean;
        } elseif (is_scalar($value) || $value === null) {
            $s = formdata_utf8((string)$value);
            if (strlen($s) > $limits['max_value_bytes']) {
                return array('fields' => array(), 'error' => 'value_too_large');
            }
            $total += strlen($s);
            $fields[formdata_utf8((string)$name)] = $s;
        } else {
            return array('fields' => array(), 'error' => 'unsupported_field');
        }

        if (count($fields) > $limits['max_fields']) {
            return array('fields' => array(), 'error' => 'too_many_fields');
        }
    }

    if ($total > $limits['max_total_bytes']) {
        return array('fields' => array(), 'error' => 'payload_too_large');
    }
    return array('fields' => $fields, 'error' => null);
}

function formdata_encode_payload(array $fields) {
    $json = json_encode($fields, JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES);
    return $json === false ? '{}' : $json;
}

function formdata_decode_payload($json) {
    $out = json_decode((string)$json, true);
    return is_array($out) ? $out : array();
}

function formdata_flatten_value($v) {
    if (is_array($v)) { return implode('; ', array_map('strval', $v)); }
    return (string)$v;
}
```

```php
<?php
if (!defined('FORMDATA')) { http_response_code(403); exit('Forbidden'); }

function formdata_rate_limited(PDO $pdo, $formId, $ip, $max, $windowSec) {
    $since = gmdate('Y-m-d H:i:s', time() - (int)$windowSec);
    $st = $pdo->prepare(
        'SELECT COUNT(*) AS c FROM submissions WHERE form_id = ? AND ip = ? AND submitted_at >= ?'
    );
    $st->execute(array((int)$formId, (string)$ip, $since));
    $row = $st->fetch();
    return ((int)$row['c']) >= (int)$max;
}

/** true = human, false = bot, null = we could not reach Cloudflare. */
function formdata_turnstile_verify($secret, $token, $ip, $http = null) {
    if ($http === null) { $http = 'formdata_http_post'; }
    $body = call_user_func($http, 'https://challenges.cloudflare.com/turnstile/v0/siteverify', array(
        'secret' => $secret, 'response' => $token, 'remoteip' => $ip,
    ));
    if ($body === null) { return null; }
    $data = json_decode((string)$body, true);
    if (!is_array($data) || !array_key_exists('success', $data)) { return null; }
    return (bool)$data['success'];
}

/** Returns the response body, or null on any transport failure. */
function formdata_http_post($url, array $data) {
    $ch = curl_init($url);
    curl_setopt($ch, CURLOPT_POST, true);
    curl_setopt($ch, CURLOPT_POSTFIELDS, http_build_query($data));
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    curl_setopt($ch, CURLOPT_CONNECTTIMEOUT, 3);
    curl_setopt($ch, CURLOPT_TIMEOUT, 5);
    $body = curl_exec($ch);
    $code = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    curl_close($ch);
    if ($body === false || $code < 200 || $code >= 300) { return null; }
    return $body;
}

function formdata_spam_check(PDO $pdo, array $form, array $post, array $meta, array $limits, $turnstileSecret, $http = null) {
    // 1. Honeypot — free, and short-circuits before any network call.
    if (isset($post['fd_hp']) && trim((string)$post['fd_hp']) !== '') { return 'honeypot'; }

    // 2. Signed timestamp — free.
    $ts  = isset($post['_ts']) ? $post['_ts'] : '';
    $sig = isset($post['_sig']) ? $post['_sig'] : '';
    $bad = formdata_check_ts($ts, $sig, $form['key_hash'], (int)$meta['now'],
                             (int)$limits['min_seconds'], (int)$limits['max_seconds']);
    if ($bad !== null) { return $bad; }

    // 3. Turnstile — one HTTPS call, only if this form wants it.
    if ((int)$form['captcha_enabled'] === 1) {
        $token  = isset($post['cf-turnstile-response']) ? $post['cf-turnstile-response'] : '';
        $result = formdata_turnstile_verify($turnstileSecret, $token, $meta['ip'], $http);
        // null means we could not reach Cloudflare. Fail OPEN: the honeypot and
        // timing checks already ran, and one Cloudflare blip must not take every
        // form on every site offline at once.
        if ($result === false) { return 'turnstile'; }
        if ($result === null) { error_log('formdata: turnstile unreachable, failing open'); }
    }
    return null;
}
```

```php
<?php
if (!defined('FORMDATA')) { http_response_code(403); exit('Forbidden'); }

function formdata_parse_emails($csv) {
    $out = array();
    foreach (explode(',', (string)$csv) as $raw) {
        // Strip anything after a CR/LF so a crafted value cannot inject headers.
        $one = trim(preg_replace('/[\r\n].*$/s', '', $raw));
        if ($one !== '' && filter_var($one, FILTER_VALIDATE_EMAIL)) { $out[] = $one; }
    }
    return $out;
}

function formdata_notification_message(array $form, $submissionId, $baseUrl, $when) {
    $link = rtrim($baseUrl, '/') . '/admin/submission.php?id=' . (int)$submissionId;
    return array(
        'subject' => 'New submission — ' . $form['name'],
        'body'    => "A new entry was submitted to \"{$form['name']}\".\n\n"
                   . "Received {$when}.\n\n"
                   . "View it here:\n{$link}\n\n"
                   . "-- \nThe submission itself is not included in this email. "
                   . "Sign in to read it.\n",
    );
}

function formdata_mail_send($to, $subject, $body, $headers) {
    return @mail($to, $subject, $body, $headers);
}

function formdata_notify(PDO $pdo, array $form, $submissionId, array $config, $mailer = null) {
    if ($mailer === null) { $mailer = 'formdata_mail_send'; }
    $recipients = formdata_parse_emails(isset($form['notify_emails']) ? $form['notify_emails'] : '');
    if (!$recipients) { return 0; }

    $when = gmdate('D, M j Y \a\t g:i A') . ' UTC';
    $msg  = formdata_notification_message($form, $submissionId, $config['base_url'], $when);
    $from = $config['mail']['from'];
    $hdrs = 'From: ' . $config['mail']['from_name'] . ' <' . $from . ">\r\n"
          . "Content-Type: text/plain; charset=UTF-8\r\n";

    $log  = $pdo->prepare('INSERT INTO notification_log (submission_id, to_email, ok, error) VALUES (?, ?, ?, ?)');
    $sent = 0;
    foreach ($recipients as $to) {
        $ok = false; $err = null;
        try {
            $ok = (bool)call_user_func($mailer, $to, $msg['subject'], $msg['body'], $hdrs);
            if (!$ok) { $err = 'mailer returned false'; }
        } catch (Throwable $e) {
            // Never let a mail failure fail the submission — the row is committed.
            $ok = false; $err = $e->getMessage();
        }
        $log->execute(array((int)$submissionId, $to, $ok ? 1 : 0, $err));
        if ($ok) { $sent++; }
    }
    return $sent;
}
```

```php
<?php
if (!defined('FORMDATA')) { http_response_code(403); exit('Forbidden'); }

function formdata_handle_submit(PDO $pdo, array $post, array $server, array $config, $http = null, $mailer = null) {
    $method = isset($server['REQUEST_METHOD']) ? $server['REQUEST_METHOD'] : 'POST';
    if (strtoupper($method) !== 'POST') {
        return array('status' => 405, 'body' => array('ok' => false, 'error' => 'method_not_allowed'));
    }

    // The key may arrive as a header or a POST field.
    $key = '';
    if (isset($server['HTTP_X_FORM_KEY'])) { $key = $server['HTTP_X_FORM_KEY']; }
    if (isset($post['_key']))              { $key = $post['_key']; }

    $form = formdata_authenticate($pdo, $key);
    if ($form === null) {
        // Deliberately identical for a malformed key, an unknown prefix, a wrong
        // secret, and an inactive form — never reveal which.
        return array('status' => 401, 'body' => array('ok' => false, 'error' => 'unauthorized'));
    }

    $limits = $config['limits'];
    $ip     = isset($server['REMOTE_ADDR']) ? $server['REMOTE_ADDR'] : '';

    if (formdata_rate_limited($pdo, (int)$form['id'], $ip, $limits['rate_max'], $limits['rate_window'])) {
        return array('status' => 429, 'body' => array('ok' => false, 'error' => 'rate_limited'));
    }

    $cleaned = formdata_clean_fields($post, $limits);
    if ($cleaned['error'] !== null) {
        return array('status' => 400, 'body' => array('ok' => false, 'error' => $cleaned['error']));
    }
    $fields = $cleaned['fields'];
    unset($fields['_key']);

    $meta = array(
        'ip'         => $ip,
        'user_agent' => isset($server['HTTP_USER_AGENT']) ? $server['HTTP_USER_AGENT'] : '',
        'referer'    => isset($server['HTTP_REFERER']) ? $server['HTTP_REFERER'] : '',
    );

    $reason = formdata_spam_check(
        $pdo, $form, $post, array('ip' => $ip, 'now' => time()),
        $limits, $config['turnstile']['secret'], $http
    );
    if ($reason !== null) {
        // Store it anyway so a false positive is recoverable in the admin, but
        // report failure so the visitor is never shown a fake success.
        formdata_store($pdo, (int)$form['id'], $fields, $meta, 'spam', $reason);
        return array('status' => 422, 'body' => array('ok' => false, 'error' => 'rejected'));
    }

    $id = formdata_store($pdo, (int)$form['id'], $fields, $meta);
    try {
        formdata_notify($pdo, $form, $id, $config, $mailer);
    } catch (Throwable $e) {
        error_log('formdata: notify failed for submission ' . $id . ': ' . $e->getMessage());
    }
    return array('status' => 200, 'body' => array('ok' => true, 'id' => $id));
}
```

```php
<?php
/**
 * Form Data client. Drop this file into any site.
 * MUST stay PHP 7.0-compatible: no arrow functions, no ??=, no typed properties.

if (!function_exists('formdata_client_secret')) {
    function formdata_client_secret($key) {
        if (!preg_match('/^fd_[0-9a-f]{8}_([0-9a-f]{64})$/', (string)$key, $m)) { return null; }
        return $m[1];
    }
}

/** Hidden inputs every Form Data form must include. */
function formdata_fields(array $opts) {
    $secret = formdata_client_secret($opts['key']);
    if ($secret === null) { return ''; }
    $now  = isset($opts['now']) ? (int)$opts['now'] : time();
    $sig  = hash_hmac('sha256', (string)$now, hash('sha256', $secret));
    // The honeypot is deliberately named fd_hp — never "website"/"phone"/"company",
    // which password managers and browser autofill will happily fill in, turning
    // real people into spam. Off-screen rather than type="hidden" so that naive
    // bots still see a fillable input.
    $hp = '<div style="position:absolute;left:-9999px;top:auto;width:1px;height:1px;overflow:hidden" aria-hidden="true">'
        . '<label>Leave this field empty'
        . '<input type="text" name="fd_hp" value="" autocomplete="off" tabindex="-1">'
        . '</label></div>';
    return $hp
        . '<input type="hidden" name="_ts" value="' . $now . '">'
        . '<input type="hidden" name="_sig" value="' . $sig . '">';
}

if (!function_exists('formdata_client_http')) {
    function formdata_client_http($url, array $data, $timeout) {
        $ch = curl_init($url);
        curl_setopt($ch, CURLOPT_POST, true);
        curl_setopt($ch, CURLOPT_POSTFIELDS, http_build_query($data));
        curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
        curl_setopt($ch, CURLOPT_CONNECTTIMEOUT, 5);
        curl_setopt($ch, CURLOPT_TIMEOUT, (int)$timeout);
        $body = curl_exec($ch);
        $code = (int)curl_getinfo($ch, CURLINFO_HTTP_CODE);
        curl_close($ch);
        if ($body === false || $code === 0) { return null; }
        return array('code' => $code, 'body' => $body);
    }
}

if (!function_exists('formdata_client_mail')) {
    function formdata_client_mail($to, $subject, $body, $headers) {
        return @mail($to, $subject, $body, $headers);
    }
}

/**
 * Send a submission. Never throws, never prints.
 * Returns array(ok, id, via, error).
 */
function formdata_submit(array $opts) {
    $http    = isset($opts['http']) ? $opts['http'] : 'formdata_client_http';
    $mailer  = isset($opts['mailer']) ? $opts['mailer'] : 'formdata_client_mail';
    $timeout = isset($opts['timeout']) ? (int)$opts['timeout'] : 10;
    $fields  = isset($opts['fields']) ? $opts['fields'] : array();

    $data = $fields;
    $data['_key'] = $opts['key'];
    if (isset($opts['captcha'])) { $data['cf-turnstile-response'] = $opts['captcha']; }

    $res = null;
    try {
        $res = call_user_func($http, $opts['endpoint'], $data, $timeout);
    } catch (Throwable $e) {
        $res = null;
    }

    if ($res !== null) {
        $decoded = json_decode($res['body'], true);
        if (is_array($decoded) && !empty($decoded['ok'])) {
            return array('ok' => true, 'id' => isset($decoded['id']) ? (int)$decoded['id'] : null,
                         'via' => 'api', 'error' => null);
        }
        // The API answered and said no (spam, bad key, oversized). That is a real
        // verdict, not an outage — emailing it would defeat the filtering.
        $err = is_array($decoded) && isset($decoded['error']) ? $decoded['error'] : 'rejected';
        return array('ok' => false, 'id' => null, 'via' => 'api', 'error' => $err);
    }

    // Transport failure: the API is unreachable. Fall back to email so no lead is lost.
    $to = isset($opts['fallback_to']) ? $opts['fallback_to'] : '';
    if ($to === '') {
        return array('ok' => false, 'id' => null, 'via' => 'api', 'error' => 'api_unreachable');
    }
    $lines = array();
    foreach ($fields as $k => $v) {
        $lines[] = $k . ': ' . (is_array($v) ? implode('; ', $v) : $v);
    }
    $from    = isset($opts['fallback_from']) ? $opts['fallback_from'] : $to;
    $subject = 'FORMDATA FALLBACK — API unreachable — ' . (isset($opts['form_name']) ? $opts['form_name'] : $opts['endpoint']);
    $body    = "The Form Data API could not be reached, so this submission is being\n"
             . "emailed instead. Paste it into the admin and check the service.\n\n"
             . implode("\n", $lines) . "\n";
    $headers = 'From: ' . $from . "\r\nContent-Type: text/plain; charset=UTF-8\r\n";

    $sent = false;
    try {
        $sent = (bool)call_user_func($mailer, $to, $subject, $body, $headers);
    } catch (Throwable $e) {
        $sent = false;
    }
    if ($sent) {
        return array('ok' => true, 'id' => null, 'via' => 'fallback', 'error' => 'api_unreachable');
    }
    return array('ok' => false, 'id' => null, 'via' => 'fallback', 'error' => 'api_unreachable_and_mail_failed');
}
```

```php
    $row = $st->fetch();
    return $row === false ? null : $row;

    $st = $pdo->prepare('SELECT * FROM users WHERE id = ?');

function formdata_verify_login(PDO $pdo, $email, $password) {
    $user = formdata_user_by_email($pdo, $email);
    if ($user === null || (int)$user['is_active'] !== 1) { return null; }
    if (!password_verify($password, $user['password_hash'])) { return null; }
    $st = $pdo->prepare('UPDATE users SET last_login_at = ? WHERE id = ?');
    $st->execute(array(gmdate('Y-m-d H:i:s'), (int)$user['id']));
    return $user;
}

function formdata_set_password(PDO $pdo, $userId, $password) {
    $st = $pdo->prepare('UPDATE users SET password_hash = ? WHERE id = ?');
    $st->execute(array(password_hash($password, PASSWORD_DEFAULT), (int)$userId));
}

function formdata_assign_form(PDO $pdo, $formId, $userId) {
    if (formdata_can_see_form($pdo, array('id' => $userId, 'role' => 'manager', 'is_active' => 1), $formId)) { return; }
    $st = $pdo->prepare('INSERT INTO form_users (form_id, user_id) VALUES (?, ?)');
    $st->execute(array((int)$formId, (int)$userId));
}

function formdata_unassign_form(PDO $pdo, $formId, $userId) {
    $st = $pdo->prepare('DELETE FROM form_users WHERE form_id = ? AND user_id = ?');
    $st->execute(array((int)$formId, (int)$userId));

function formdata_user_forms(PDO $pdo, array $user) {
    if ((int)$user['is_active'] !== 1) { return array(); }

    $st = $pdo->prepare(
        'SELECT f.* FROM forms f JOIN form_users fu ON fu.form_id = f.id
         WHERE fu.user_id = ? ORDER BY f.name'

    $st->execute(array((int)$user['id']));
    return $st->fetchAll();

    $st->execute(array((int)$formId, (int)$user['id']));
    $row = $st->fetch();
```

```php
<?php
if (!defined('FORMDATA')) { http_response_code(403); exit('Forbidden'); }

/**
 * Render a submission payload. BOTH keys and values arrive from the public
 * internet, so both are escaped. A field named <script> must be as safe as
 * one named email.
 */
function formdata_render_payload_table(array $payload) {
    if (!$payload) { return '<p class="muted">This submission had no fields.</p>'; }
    $out = '<table class="payload">';
    foreach ($payload as $key => $value) {
        $out .= '<tr><th>' . formdata_esc($key) . '</th><td>'
              . formdata_esc(formdata_flatten_value($value)) . '</td></tr>';
    }
    return $out . '</table>';
}

function formdata_preview_text(array $payload, $max = 80) {
    if (!$payload) { return '—'; }
    $parts = array();
    foreach ($payload as $value) {
        $s = trim(formdata_flatten_value($value));
        if ($s !== '') { $parts[] = $s; }
    }
    if (!$parts) { return '—'; }
    $text = implode(' — ', $parts);
    if (mb_strlen($text) > $max) { $text = mb_substr($text, 0, $max) . '…'; }
    return formdata_esc($text);
}
```

```php
<?php
if (!defined('FORMDATA')) { http_response_code(403); exit('Forbidden'); }

function formdata_csv_columns(array $rows) {
    $cols = array();
    foreach ($rows as $r) {
        foreach (array_keys($r['payload']) as $k) {
            if (!in_array($k, $cols, true)) { $cols[] = $k; }
        }
    }
    return $cols;
}

/**
 * Neutralize spreadsheet formula injection. A value beginning = + - @ or a
 * control character is executed by Excel and Sheets when the export is opened,
 * so it is prefixed with an apostrophe and rendered as text.
 */
function formdata_csv_cell($value) {
    $s = (string)$value;
    if ($s === '') { return ''; }
    $first = substr($s, 0, 1);
    if (strpos("=+-@\t\r", $first) !== false) { return "'" . $s; }
    return $s;
}

function formdata_csv_quote($s) {
    if (preg_match('/[",\n\r]/', $s)) { return '"' . str_replace('"', '""', $s) . '"'; }
    return $s;
}

function formdata_csv_string(array $rows) {
    $cols   = formdata_csv_columns($rows);
    $header = array('id', 'submitted_at', 'status');
    foreach ($cols as $c) { $header[] = formdata_csv_cell($c); }
    $out = implode(',', array_map('formdata_csv_quote', $header)) . "\n";

    foreach ($rows as $r) {
        $line = array((string)$r['id'], (string)$r['submitted_at'], (string)$r['status']);
        foreach ($cols as $c) {
            $v = array_key_exists($c, $r['payload']) ? formdata_flatten_value($r['payload'][$c]) : '';
            $line[] = formdata_csv_cell($v);
        }
        $out .= implode(',', array_map('formdata_csv_quote', $line)) . "\n";
    }
    return $out;
}
```
